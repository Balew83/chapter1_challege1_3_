# Gestalt Psychology Interactive Learning Lab

A responsive, browser-only learning site built with semantic HTML, CSS, and vanilla JavaScript. It has no server, API, external image assets, or package dependencies.

## Open the site on Windows

1. Open VS Code and create a folder named `gestalt-psychology`.
2. Create `index.html`, `style.css`, `script.js`, and `README.md` inside the folder.
3. Paste each file's source code into the matching file and save all four in the same folder.
4. Open the folder in File Explorer and double-click `index.html` (or open it in Chrome).

## Use the learning lab

- Navigate with the links at the top of the page: Home, Learn Principles, Interactive Lab, Compare Designs, Quiz, Design Checklist, and About.
- Review each principle card for its definition, everyday explanation, interface example, and open its comparison in the lab.
- In the Interactive Lab, select a principle and use **WITH Principle**, **WITHOUT Principle**, and **Compare Both**. **Reset** returns to the Proximity example: three clear groups versus evenly spaced dots. Common Fate has a start/pause control.
- Compare Designs shows the seven foundational principles side by side and explains what changed and why that matters in UI/UX.
- In the quiz, select an answer, choose **Check answer**, then continue with **Next Question**. Questions are shuffled without repeats within a round. Use **Restart Quiz** to begin another round. The score tracks answered, correct, incorrect, and percentage, with a learning recommendation.
- Answer Yes, No, or Not Sure for each Design Checklist item. Once all are answered, the page shows a learning reflection. Clear answers to start over. The result is a learning aid, not a scientifically validated psychological measurement.
- Use the theme control to switch between light and dark mode. The page supports keyboard navigation, responsive layouts, and reduced-motion preferences.
